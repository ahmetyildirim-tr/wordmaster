WORDMASTER - iPhone Safari kelime ezberleme uygulaması

Dosyalar: index.html, manifest.webmanifest, icon.svg

KULLANIM
1. Bu üç dosyayı aynı klasörde bir HTTPS statik web sunucusuna yükleyin (ör. GitHub Pages veya Netlify).
2. iPhone Safari'de yayımlanan HTTPS adresini açın.
3. Safari Paylaş > Ana Ekrana Ekle ile uygulama simgesini ekleyin.
4. Kategoriler, alt listeler ve kelimeler ekleyin. Hazır 30 kelime vardır.
5. Çalış ekranında liste, yön, filtre ve test biçimini seçin.
6. Ayarlar > JSON yedeği indir ile düzenli yedek alın.

NOTLAR
- Veriler cihazdaki tarayıcı localStorage alanında tutulur; farklı cihazlara otomatik senkronize edilmez.
- Safari verilerini silmek kayıtları silebilir. JSON yedeği önemlidir.
- HTML dosyasını doğrudan Dosyalar'dan açmak yerine HTTPS üzerinden kullanın; bu, depolama ve ana ekrana ekleme için daha güvenilirdir.
- Kelime kartlarında doğru/yanlış işaretleme; quiz ve yazma modunda cevaplar öğrenme tekrar tarihlerini günceller.
- Akıllı tekrar: doğru cevapta aralık 1, 3, sonra artan günler; yanlışta aynı gün yeniden tekrar için uygun olur.
- Karışık modda her soru için yön bağımsız rastgele seçilir.
- CSV başlıkları english,turkish,example şeklindedir.
